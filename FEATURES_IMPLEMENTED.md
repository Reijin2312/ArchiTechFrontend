# Реализованные фичи профиля

## 📋 Обзор

Полная модернизация системы профилей с добавлением визуальных улучшений, новых компонентов и функциональности.

## ✅ Новые компоненты

### 1. **DragDropZone** (`src/shared/ui/DragDropZone.tsx`)
- Drag & drop загрузка файлов с валидацией
- Проверка типа и размера файла
- Визуальная обратная связь при перетаскивании
- Поддержка любых типов файлов через props

### 2. **ProgressBar** (`src/shared/ui/ProgressBar.tsx`)
- Анимированная полоса прогресса с Framer Motion
- Цветовые варианты: sky, emerald, amber, indigo
- Опциональный процент справа
- Плавная анимация изменения значения

### 3. **Badge** (`src/shared/ui/Badge.tsx`)
- Компонент достижений с иконкой
- Состояния: unlocked / locked
- Тултип с описанием
- Отображение даты получения
- Hover-эффекты

### 4. **StatusSelect** (`src/shared/ui/StatusSelect.tsx`)
- Выбор статуса в стиле Discord
- 4 варианта: online, idle, dnd, offline
- Кастомный текст статуса (макс 100 символов)
- Выпадающее меню с радио-кнопками

### 5. **SocialLinks** (`src/shared/ui/SocialLinks.tsx`)
- Редактор социальных ссылок
- Поддержка: Discord, Telegram, VK, YouTube, Twitch, GitHub, Custom
- Режимы: редактирование / только просмотр
- Иконки и цветовая дифференциация

### 6. **ProfileBanner** (`src/shared/ui/ProfileBanner.tsx`)
- Баннер/обложка профиля
- Drag & drop загрузка (только изображения, макс 5MB)
- Кнопка удаления
- Полноразмерный режим просмотра

### 7. **ThemeSelector** (`src/shared/ui/ThemeSelector.tsx`)
- 6 цветовых тем профиля: default, ocean, sunset, forest, purple, fire
- Превью каждой темы
- Анимированный выбор с layoutId
- Helper-функция `getThemeGradient()` для применения

### 8. **SkinGallery** (`src/shared/ui/SkinGallery.tsx`)
- Галерея сохранённых скинов
- Сохранение с именем + дата
- Быстрое переключение
- Удаление скинов
- Сетка с превью

### 9. **Skin3DPreview** (`src/shared/ui/Skin3DPreview.tsx`)
- 3D-превью скина с skinview3d
- Автоповорот
- Управление камерой (орбит-контролы)
- Toggle кнопка для скрытия/показа
- Анимация появления/исчезновения

### 10. **AboutServerPage** (`src/pages/AboutServerPage.tsx`)
- Страница истории сервера
- Hero-скриншот с описанием
- 4 сезона с расширяемыми карточками
- Список игроков каждого сезона с аватарами
- Галереи скриншотов по сезонам
- SEO-оптимизация

## 🎨 Обновлённые страницы

### **SettingsProfilePage** (`src/pages/SettingsProfilePage.tsx`)

#### Добавлено:
- **Прогресс заполнения профиля** (0-100%) с цветным индикатором
- **Загрузка баннера** через DragDropZone
- **3D-превью скина** с toggle-кнопкой
- **Выбор статуса** с кастомным текстом
- **Социальные ссылки** (редактируемые)
- **Выбор темы профиля** (6 вариантов)
- **Галерея скинов** (сохранение/удаление/выбор)
- **Ачивки** (30 заглушек с разблокированными/заблокированными)

#### Новый state:
```typescript
- bannerUrl, profileTheme, customStatus
- socialLinks (discord, telegram, vk, youtube, twitch, github)
- savedSkins (массив с именем, URL, датой)
- achievements (30 ачивок с unlock-статусом)
- showSkin3D (toggle для 3D-превью)
```

#### Расчёт прогресса:
- Email: 10%
- Bio: 10%
- Аватар: 15%
- Баннер: 10%
- Социальные ссылки (минимум 1): 15%
- Статус: 5%
- Тема: 5%
- Сохранённые скины (минимум 1): 10%
- Разблокированные ачивки (минимум 5): 20%

### **UserProfilePage** (`src/pages/UserProfilePage.tsx`)

## 🎯 Особенности реализации

### Анимации (Framer Motion):
- Плавное появление/исчезновение элементов
- AnimatePresence для условного рендера
- layoutId для плавных переходов выбора темы

- Типы файлов (изображения для баннера/аватара)

- Длина текста (100 символов для статуса)

### Типобезопасность:
- Все компоненты с TypeScript типами
- Props с JSDoc комментариями
- Правильная типизация всех state variables

### Адаптивность:
- Mobile-first подход
- Grid layouts для разных экранов
- Responsive классы Tailwind
