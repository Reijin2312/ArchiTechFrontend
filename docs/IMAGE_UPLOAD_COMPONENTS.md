# Компоненты загрузки изображений

Система компонентов для красивой загрузки и отображения изображений с индикаторами прогресса и плавной анимацией.

## Компоненты

### ImageWithLoader
Универсальный компонент для отображения изображений с автоматическим индикатором загрузки и плавным появлением.

**Использование:**
```tsx
import { ImageWithLoader } from '@/shared/ui/image';

<ImageWithLoader
  src="/path/to/image.jpg"
  alt="Описание"
  className="w-full h-64 object-cover rounded-lg"
  placeholderClassName="w-full h-64"
  onLoad={() => console.log('Загружено')}
  onError={() => console.log('Ошибка')}
/>
```

**Особенности:**
- Автоматический индикатор загрузки (крутящийся спиннер)
- Плавное появление при загрузке (fade-in анимация)
- Обработка ошибок с понятным UI
- Placeholder с иконкой если нет src

### UploadProgress
Круговой индикатор прогресса загрузки с процентами.

**Использование:**
```tsx
import { UploadProgress } from '@/shared/ui/image';

<UploadProgress
  progress={75} // 0-100
  onCancel={() => console.log('Отменено')}
  size="lg" // 'sm' | 'md' | 'lg'
/>
```

**Особенности:**
- Красивая круговая анимация прогресса
- Опциональная кнопка отмены
- Три размера: sm (40px), md (60px), lg (80px)
- Плавная анимация изменения прогресса

### ImageUploadPreview
Полноэкранный компонент предпросмотра загружаемого изображения с прогрессом.

**Использование:**
```tsx
import { ImageUploadPreview } from '@/shared/ui/image';

<ImageUploadPreview
  file={selectedFile}
  progress={uploadProgress}
  onCancel={() => cancelUpload()}
  error={uploadError}
  className="h-64"
/>
```

**Особенности:**
- Показывает превью изображения с blur эффектом
- Индикатор прогресса поверх превью
- Автоматическое отображение ошибок
- Анимация успешной загрузки с галочкой

## Интеграция в существующие компоненты

### Чат (SocialFloatingButton)
- Добавлена поддержка загрузки изображений с круговым индикатором
- Временное сообщение с прогрессом загрузки
- Плавная загрузка изображений от собеседников
- Исправлен баг с исчезновением изображений после перезагрузки

### Профиль
Все компоненты загрузки профиля обновлены:
- **BannerPicker** - баннер профиля
- **WallpaperPicker** - обои профиля  
- **AvatarPicker** - аватар
- **SkinPicker** - скин персонажа
- **ProfileBanner** - отображение баннера

Все используют ImageWithLoader для плавной загрузки с индикаторами.

## Исправленные баги

### Проблема с отображением изображений в чате
**Было:**
- При первой отправке отображалась мелкая иконка вместо полноразмерного изображения
- После перезагрузки страницы сообщения с изображениями исчезали
- Нет обратной связи о процессе загрузки

**Стало:**
- Изображения корректно отображаются в полном размере
- Временное сообщение с индикатором загрузки при отправке
- Плавная загрузка всех изображений с спиннером
- Изображения сохраняются после перезагрузки (imageUrl + imagePath)

## Технические детали

### Состояние загрузки в чате
```tsx
const [uploadingImages, setUploadingImages] = useState<Map<string, { progress: number; file: File }>>(new Map());
```

Отслеживает состояние загрузки каждого изображения по уникальному ID.

### Симуляция прогресса
Для демонстрации используется симуляция прогресса (в идеале заменить на реальный onUploadProgress из axios):
```tsx
const progressInterval = setInterval(() => {
  setUploadingImages(prev => {
    const current = prev.get(tempMessageId);
    if (current && current.progress < 90) {
      const next = new Map(prev);
      next.set(tempMessageId, { ...current, progress: current.progress + 10 });
      return next;
    }
    return prev;
  });
}, 100);
```

### Плавная анимация
Используется framer-motion для всех анимаций:
- fade-in при загрузке изображений
- плавное изменение прогресса
- анимация появления/исчезновения индикаторов
